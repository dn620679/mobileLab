# 전선 돌파 · BREAKLINE

병사 한 명으로 출발해 보급 상자를 사격으로 부수고, 분대를 늘려 적의 연속 공세를 막는 3D 레일 슈터입니다.

## 실행과 조작

- `squad-rail-shooter/index.html`을 다운로드해서 WebGL을 지원하는 브라우저로 열 수 있도록 구성했습니다. CSS와 JavaScript, 3D 모델 생성 코드가 파일 안에 있어 추가 파일이나 런타임 네트워크 요청이 없습니다.
- 모바일에서는 손가락 하나로 좌우로 드래그합니다. PC에서는 마우스 드래그, 방향키 또는 A/D를 쓸 수 있습니다. 사격은 자동입니다.
- 왼쪽 전투 구역에는 적이 계속 쏟아집니다. 적이 화면 아래 표시된 방어선을 통과하면 방어선 내구도가 줄어듭니다. 내구도 또는 병력이 0이면 패배합니다.
- 오른쪽 보급로에서 상자를 사격하면 병력, 공격력, 연사, 산탄, 관통을 강화할 수 있습니다. 보급로에 있는 동안에도 적은 계속 전진합니다.
- 각 작전의 적 무리 사이로 대형 지휘관이 여러 차례 등장합니다. 붉은 공격 예고 구역에서 벗어나 충격을 피하고, 마지막 지휘관까지 모두 처치하면 승리합니다.
- 외곽 검문소, 붉은 화물 지구, 최후의 방벽의 세 작전이 있습니다. 얻은 코인으로 시작 병력, 공격력, 연사를 영구 강화할 수 있습니다. 해금, 코인, 기록, 설정을 `localStorage`에 저장합니다. 진행 중인 라운드는 다시 열면 처음부터 시작합니다.

## GitHub Pages

저장소의 **Settings → Pages → Build and deployment → Deploy from a branch**에서 `main`과 `/(root)`를 선택합니다. 배포되면 프로젝트 기본 주소의 끝에 `/squad-rail-shooter/`를 붙여 접속합니다. 루트와 기존 게임은 별도의 진입 파일을 사용합니다.

[GitHub Pages 게시 소스 설정 문서](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## 파일 및 검증

- `index.html`은 작전 데이터와 전투 시뮬레이션, 원시 WebGL 렌더러, UI와 입력을 포함합니다. 전장은 깊이 테스트를 사용하는 3D 삼각형으로 그립니다. 상자 표식과 효과 문구에는 별도의 2D 오버레이를 사용합니다. 외부 라이브러리가 없습니다.
- `game.test.cjs`는 HTML 안의 실제 게임 코드를 실행합니다. 저장소 루트에서 `node --test squad-rail-shooter/game.test.cjs`로 검사합니다. 시작, 이동, 사격, 상자 파괴와 합류, 적 처치, 패배와 재시작, 연속 스폰과 방어선 붕괴, 세 작전의 지휘관 공격 및 승리, 저장 데이터 복원을 포함합니다.
- OpenGL ES에서 실제 셰이더를 컴파일하고 390×844와 540×844 전장을 그려 검증했습니다. 테스트용 Chrome이 WebGL 컨텍스트를 제공하지 않아 Chrome 전투 플레이, Android 터치와 프레임률, 기기에서의 로컬 파일 실행은 별도 확인이 필요합니다.
