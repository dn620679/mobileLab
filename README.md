# 괴수 해체업자

거대 괴수의 사체를 해체해 나온 부산물을 정제하고, 왕국의 의뢰를 받아 작업장을 키우는 2D 클리커 게임입니다.

## 실행

`index.html`을 다운로드해 브라우저에서 엽니다. 스타일, 게임 코드, 이미지를 모두 HTML 한 파일에 담았으므로 Android에서 파일 앱으로 열 때도 함께 받을 파일이 없습니다. 게임 실행에는 인터넷 연결이나 서버가 필요하지 않습니다.

브라우저가 파일의 로컬 저장소 접근을 허용하면 자동 저장됩니다. 일부 모바일 파일 미리보기나 비공개 브라우징에서는 저장이 제한될 수 있습니다. 같은 브라우저에서 같은 경로의 파일을 열면 진행을 이어갈 수 있습니다.

## 조작과 시스템

- **해체장**에서 괴수 위의 번호 또는 아래의 부위 버튼을 누릅니다. 자동 절단기는 마지막에 선택한 부위를 우선 처리합니다. 모든 부위를 처리하면 보상을 받고 같은 사체를 다시 입고하거나 목록에서 다른 괴수를 입고할 수 있습니다.
- **자동 머지 작업장**은 같은 계열과 등급의 재료를 세 개씩 합칩니다. 계열별로 머지를 끄거나 상한과 1등급 보존 수량을 정할 수 있습니다. 모든 괴수가 공유하는 마정석 계열에는 여섯 등급이 있습니다. 보관함이 가득 차면 미수거 재료가 작업장에 남으며 저장에도 포함됩니다.
- **가공·제작**에서는 네 가지 설비로 가공품 10종과 완제품 15종을 만듭니다. 필요 재료, 설비 레벨, 작업 시간은 레시피에 표시됩니다. 진행 중인 작업은 브라우저를 닫았다 열어도 예약된 완료 시각을 기준으로 이어집니다. 자동 해체는 게임이 실행 중일 때 작동합니다.
- **판매대**에서 선택한 품목을 1개, 10개 또는 가능한 최대 수량만큼 판매합니다. 설정의 의뢰 재고 보호를 켜면 현재 계약의 미납 수량을 판매와 자동 머지에서 보호합니다. 가공·제작을 직접 시작할 때는 레시피 재료가 차감됩니다.
- **납품 게시판**에는 현재 만들 수 있는 물품의 계약 세 건이 올라옵니다. 품목별로 한 개씩 또는 가능한 물량을 납품할 수 있습니다. 완납하면 골드와 해체 표식을 받고 새 계약이 들어옵니다. 일부 계약에는 장비 강화 포인트가 추가됩니다.
- **강화**에서 해체력, 자동 절단, 부산물, 머지, 보관·수거, 설비와 작업 슬롯을 개선합니다. 다음 괴수의 입고 허가에는 골드, 이전 괴수 처리 횟수, 해체 표식이 필요합니다.
- **설정**에서 효과음과 모션을 조절하거나 확인 절차를 거쳐 저장을 초기화할 수 있습니다.

## 아트

이미지 생성 도구로 어두운 판타지 픽셀아트 스타일의 괴수 5종, 철제 해체장, 설비 4종, 재료 스프라이트 시트, 마정석 6단계 스프라이트 시트를 제작했습니다. 괴수와 배경은 로컬 WebP/JPEG로, 설비와 아이콘은 투명 PNG 아틀라스로 적용했습니다. 아틀라스에는 생성된 아이콘과 게임에 맞춰 별도로 제작한 등급 및 품목 아이콘이 함께 들어 있습니다. 부위 손상은 괴수 이미지의 부위별 레이어를 어둡게 하거나 제거하는 방식으로 표현합니다. UI 장식과 낙하·머지 파티클은 CSS와 Canvas로, 효과음은 Web Audio로 구현했습니다.

## 개발 및 검증

`data.js`에 괴수, 레시피, 드롭, 의뢰를 정의합니다. `game.js`는 재고와 저장을 포함한 게임 규칙, `app.js`는 입력과 화면, `effects.js`는 애니메이션과 효과음을 담당합니다.

개발 중에는 `index.template.html`과 각 소스 파일을 수정합니다. 변경 후 `node scripts/build-standalone.js`로 배포용 `index.html`을 갱신합니다.

개발용 테스트는 Node.js 20 이상에서 실행합니다.

```sh
node --test tests/*.test.js
```

테스트는 괴수별 공통 드롭, 머지의 3대 1 보존, 상한과 예약, 레시피 25종, 납품 보상과 저장 복원, 1만 단위 이상의 대량 드롭, 렌더링 오브젝트 상한, 첫 해금까지의 플레이 시뮬레이션을 검사합니다. 브라우저의 실제 터치 조작과 프레임률은 이 테스트의 범위 밖입니다.
